# Tabuada

# Gerador de tabuada em python 🐍

* Este é um projeto simples para treinar a lógica de programação em python

## 🚀 Funcionalidades

* O usuário digita um número
* O programa gera a tabuada de 1 a 10
* Utiliza laço de repetição while para processamento

## 🛠️ Tecnologias

* Conceitos de: input de dados, F-string e estruturas de repetição

## 📖 Como executar

Basta ter o programa Python instalado e rodar o programa:

```python 
python tabuada.py 
```
